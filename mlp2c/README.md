# mlp2c

**연산 예산에서 신경망 구조를 역산하고, 학습된 가중치를 MCU 용 C 코드로 내보낸다.**

```bash
make budget   # 예산 계산기만
make test     # 학습 -> 내보내기 -> C 추론 -> Python 과 대조
```

---

## 왜 이 순서인가

모델을 먼저 만들고 나중에 줄이는 방식은 임베디드에서 잘 실패한다.
성능이 나오는 구조를 찾아 놓고 나서 "이게 타깃에 안 들어간다"는 것을
알게 되면, 줄이는 작업이 아니라 **설계를 처음부터 다시 하는 작업**이 된다.
줄이는 것과 처음부터 그 크기로 설계하는 것은 다른 일이다.

그래서 순서를 뒤집는다.

```
코어 주파수 x 마감 시간  =  가용 클럭
가용 클럭 / MAC 당 사이클  =  파라미터 상한
그 상한 안에서만 구조를 고른다
```

`budget.py` 가 이 계산을 하고, 상한에 들어가는 구조를 큰 것부터 나열한다.

```
$ python3 budget.py --mhz 120 --deadline-us 1000 --in 8 --out 2 --max-nodes 64

코어            120 MHz
마감            1000 us
가용 클럭       120,000
MAC 당 사이클   1
파라미터 상한   120,000
...
```

`--cycles-per-mac` 은 보수적으로 잡는 편이 낫다. 여유가 남으면 나중에
늘리면 되지만, 모자라면 되돌아갈 곳이 없다. FPU 가 없는 코어나
메모리 접근이 느린 구성에서는 1 보다 훨씬 커진다.

이 계산은 **MAC 만 센다.** 활성화 함수, 메모리 접근, 호출 오버헤드는
빠져 있다. 그래서 상한은 설계 출발점이지 보증이 아니다.
마지막에는 타깃에서 실측해야 한다.

## 파이프라인

```
train_synth.py  ──►  model.npz
                       │
export_c.py  ──────────┴──►  weights.h   (const float, Flash 배치)
                                 │
runtime/mlp.c  ──────────────────┴──►  C 추론
                                          │
                                   Python 출력과 대조
```

`make test` 가 이 전체를 돌리고 마지막 대조까지 한다.

```
구조     8-16-12-2
파라미터 374  (Flash 1496 B)
scratch  32 floats
샘플     16개  최대 오차 4.768e-07  (허용 1e-04)
OK — Python 과 C 의 출력이 일치한다
```

**마지막 대조가 이 저장소의 핵심이다.** 이식에서 가장 먼저 깨지는 곳이
여기다 — 가중치 순서, 행/열 방향, 활성화를 마지막 층에도 적용해 버리는 실수.
학습 쪽과 추론 쪽이 같은 값을 내는지 자동으로 확인하지 않으면,
나중에 "정확도가 왜 이러냐"를 모델 탓으로 오해하며 시간을 쓴다.

## 런타임

```c
mlp_t m = mlp_model();          /* weights.h 가 제공 */
float scratch[64];              /* mlp_scratch_floats(&m) 이상 */
float out[MLP_N_OUT];

mlp_forward(&m, input, out, scratch);
```

- 동적 할당 없음. scratch 는 호출자가 준다 (`2 * max(dims)` floats).
- 은닉층 ReLU, 출력층 항등. 회귀를 전제로 한다.
- 가중치는 `const` 라 Flash 에 놓인다. RAM 은 scratch 와 출력뿐이다.
- 층 수와 각 층 크기는 헤더의 `dims[]` 로 들어가므로 런타임 코드는 그대로 쓴다.

생성되는 헤더는 이런 모양이다.

```c
/* 구조 8-16-12-2  ·  파라미터 374  ·  Flash 1,496 B */
#define MLP_N_LAYERS 3
#define MLP_N_IN     8
#define MLP_N_OUT    2
static const int   mlp_dims_[] = {8, 16, 12, 2};
static const float mlp_W0_[]   = { ... };
```

## 범위 밖

- **정수 양자화.** 여기서는 float32 로 내보낸다.
  int8 양자화는 보정 데이터와 스케일 설계가 따라붙는 별개의 주제다.
- **학습 프레임워크.** `train_synth.py` 는 NumPy 로만 쓴 최소 구현이다.
  목적이 학습이 아니라 "학습된 모델을 타깃에서 같은 값으로 돌리는 것"이라
  의존성을 늘리지 않았다. Keras·PyTorch 에서 뽑은 가중치도
  `W0,b0,W1,b1,...` 이름으로 `.npz` 에 담으면 `export_c.py` 가 그대로 받는다.
- **실제 연구 데이터.** 학위 연구에 쓴 데이터는 피험자 데이터라 공개하지 않는다.
  여기서는 같은 성격의 문제(다채널 센서 → 연속값 회귀)를 합성으로 만든다.
