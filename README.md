# Embedded Portfolio

임베디드 소프트웨어 · 펌웨어 엔지니어 **김윤성**의 공개 저장소입니다.

방산 전자장비 연구소에서 3년 3개월간 제어 SW · 펌웨어를 개발했고,
석사 과정에서 저사양 MCU 실시간 추론을 위한 모델 경량화를 연구했습니다.
ARM Cortex-M · TI DSP 펌웨어와 Cortex-A 기반 Embedded Linux 응용을 함께 다룹니다.

**→ [경력 요약 전문](./PROFILE.md)**

여기에는 실무에서 반복해 다뤄 온 문제를 **처음부터 다시 작성한 독립 구현**으로
담았습니다. 각 항목은 빌드되고 테스트가 돕니다.

## 담기지 않은 것

이 저장소에는 **전 직장과 고객사의 자산이 일절 포함되어 있지 않습니다.**

- 재직 중 수행한 사업의 소스 코드 · 설계 자료 · 규격 산출물
- 사업명 · 체계명 · 발주처 · 고객사 · 부품 규격
- 수주 개발 납품물의 코드
- 학위 연구의 피험자 데이터
- 상세 경력기술서 · 포트폴리오 원본 (발주처 · 기여도 · 사업별 수치가 들어 있어
  채용 절차에서 개별 제출합니다. 이 저장소에는 공개판 요약만 둡니다.)

여기 있는 코드는 전부 이 저장소를 위해 새로 작성한 것이고, 저작권은 저에게 있습니다.
설명에 쓰인 기법은 공개된 표준과 논문에 근거합니다.
